# Project Overview

This project was completed as part of the Mechanical Engineering Track using the Onshape cloud-based CAD platform. The purpose of this project is to create a three-dimensional Batman logo model by transforming a two-dimensional reference shape into a solid 3D object using CAD modeling techniques.

The final model was exported as an STL file, which is the standard format used for additive manufacturing and 3D printing. The project demonstrates the basic engineering workflow involved in creating digital mechanical models and preparing them for manufacturing applications.

---

# Project Background

Computer-Aided Design (CAD) has become one of the most important tools in modern engineering. Engineers use CAD software to design, modify, analyze, and manufacture products efficiently.

This project introduces the basic concepts of mechanical modeling by designing a recognizable logo using engineering design principles and converting it into a printable three-dimensional object.

# Design Workflow

The engineering workflow followed during this project included:

1. Selecting the Batman logo as the design reference.
2. Preparing the reference shape inside Onshape.
3. Creating the initial sketch.
4. Refining the geometry until the desired profile was achieved.
5. Converting the sketch into a solid body using the Extrude feature.
6. Inspecting the final model.
7. Exporting the completed model in STL format.
8. Uploading the STL file and documentation to GitHub.
