## Project Overview
This project focuses on designing a three-dimensional Batman logo using the Onshape CAD platform. The model was created by estimating the dimensions of the selected shape and converting it into a 3D model suitable for digital manufacturing and 3D printing.

---

## Project Objectives
- Practice using the Onshape CAD software.
- Estimate the dimensions of a selected shape and convert it into a 3D model.
- Export the completed design as an STL file.
- Prepare the project for submission through GitHub.

---

## Software Used
- Onshape

---

## Output Files
- Batman.stl

---

## Design Process
1. Selected the Batman logo as the design shape.
2. Estimated the dimensions of the shape.
3. Created and modified the 3D model using Onshape.
4. Exported the final design in STL format.
5. Uploaded the required files to GitHub.
